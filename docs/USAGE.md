# راهنمای استفاده

## مسیر یک ویدیو
1. **‎/new** → کانال → نوع (آموزشی / تبلیغاتی / خبری) → قالب (۱۶:۹ یا شورتز ۹:۱۶) → مدت → موضوع.
   برای خبر، لینک منابع را در همان پیام (خط‌های بعدی) بفرستید.
2. **متن**: Gemini استوری‌بورد را می‌نویسد (JSON با اعتبارسنجی zod و یک بار اصلاح خودکار). متن کامل صحنه‌ها با دکمه‌های «تأیید / اصلاح / رد» برایتان می‌آید.
3. **پیش‌نمایش**: پس از تأیید متن، صدا (Gemini TTS → flash-lite → edge-tts)، هم‌ترازی کلمه‌به‌کلمه (CTC فارسی)، موسیقی و پیش‌نمایش ۷۲۰p ساخته می‌شود و همراه برگه‌ی اثبات زیرنویس در تلگرام می‌آید.
4. **نهایی**: پس از تأیید پیش‌نمایش، رندر ۱۰۸۰p (یا 4K برای پیانووا)، کنترل کیفیت کامل و تحویل: MP4، SRT، تامبنیل‌ها، فصل‌ها و متن عنوان/توضیحات. لینک‌ها از Worker می‌آیند و فایل‌ها در Release با تگ `job-<id>` ذخیره می‌شوند. اگر Drive تنظیم شده باشد، یک نسخه در Google Drive هم ذخیره می‌شود.

هیچ خروجی‌ای بدون تأیید شما نهایی نمی‌شود. «اصلاح» یادداشت شما را می‌گیرد و متن را بازنویسی می‌کند.

## دستورها
| دستور | کار |
|---|---|
| ‎/new | ساخت ویدیوی تازه |
| ‎/status | وضعیت آخرین کار |
| ‎/jobs | ده کار آخر |
| ‎/cancel | لغو کار جاری |
| ‎/quota | سهمیه‌ی امروز و وضعیت کلید خاموشی |
| ‎/templates | سبک‌ها و قالب‌های مجاز هر کانال |
| ‎/panel | لینک ورود یک‌بارمصرف به پنل وب |

## پنل وب
پنل روی همان Worker است: فهرست کارها، پیش‌نمایش زنده با Remotion Player (همان کامپوزیشن رندر نهایی)، ویدیوی رندرشده، متن صحنه‌ها، جدول زمان‌بندی زیرنویس، گزارش QA و لینک فایل‌ها. تأیید/رد/اصلاح از پنل هم ممکن است.

## اجرای محلی (بدون تلگرام)
```bash
cd pipeline
AMF_PYTHON=$(which python3) npx tsx src/cli.ts produce --id demo --storyboard ../samples/pianova-lesson.json --stage both
```
خروجی در `.work/jobs/demo/out/` است.

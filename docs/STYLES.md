# سبک‌های موشن

هر سبک یک پیش‌تنظیم کامل است: منحنی‌های حرکت (هیچ حرکت اصلی خطی نیست)، فنر، ترنزیشن‌ها، پس‌زمینه، افکت‌ها، دوربین، رنگ‌بندی و فونت‌های مجاز. هر استوری‌بورد یک سبک اصلی و حداکثر دو سبک مکمل دارد، و فقط سبک‌های مجاز همان کانال.

## ترنزیشن‌ها
fade، slide، maskWipeRtl (پاک‌کن راست‌به‌چپ مخصوص فارسی)، clockWipe، lightSweep، glitch، whipPan، filmBurn، hardCut، zoomBlur. مدت هر ترنزیشن ۸ تا ۱۸ فریم است و زمان‌بندی صدا و زیرنویس با هم‌پوشانی ترنزیشن‌ها جبران می‌شود.

## صدا و موسیقی
صدای گوینده ‎−16 LUFS، موسیقی حدود ‎−28 LUFS با داکینگ sidechain زیر صدا، خروجی نهایی ‎−14 LUFS و True Peak حداکثر ‎−1 dBTP. موسیقی فقط از دفتر حقوق (ledger) هر برند انتخاب می‌شود و هر قطعه فیلد rights دارد.
